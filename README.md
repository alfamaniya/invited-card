# کارت دعوت مانیا 💌

یک کارت دعوت فارسی، تمام‌صفحه و تعاملی با پس‌زمینه‌ی گرادیانی متحرک، طراحی شیشه‌ای و تقویم شمسی.

## اجرای پروژه
فایل `index.html` را در مرورگر باز کنید. برای انتشار از طریق GitHub Pages، سه فایل زیر باید در ریشه‌ی شاخه‌ی `main` باشند.

## ساختار فایل‌ها
- `index.html` — ساختار سه صفحه و منطق تعامل‌ها
- `style.css` — طراحی شیشه‌ای، پس‌زمینه‌ی پویا، واکنش‌گرایی و انیمیشن‌ها
- `README.md` — راهنمای پروژه

## امکانات
- صفحه‌ی آغاز تمام‌صفحه با گرادیان متحرک و پس‌زمینه‌ی گریدی
- جابه‌جایی به صفحه‌ی دعوتنامه بدون باز شدن پنجره‌ی کوچک
- دکمه‌های شیشه‌ای با افکت‌های تعاملی
- دکمه‌ی «نه» که هنگام نزدیک شدن اشاره‌گر یا لمس، از دکمه‌ی «آره» و پیام‌ها فاصله می‌گیرد
- صفحه‌ی تمام‌صفحه‌ی انتخاب تاریخ شمسی برای روزهای باقی‌مانده‌ی سال ۱۴۰۵
- پیام تصادفی و دوستانه از طرف مانیا با انتخاب تاریخ
- طراحی واکنش‌گرا برای موبایل و دسکتاپ و پشتیبانی از کاهش حرکت انیمیشن‌ها

## نکته
انتخاب تاریخ در همین صفحه نمایش داده می‌شود و به سرور ارسال یا در جایی ذخیره نمی‌شود. فونت Vazirmatn از Google Fonts بارگیری می‌شود؛ در صورت نبود اینترنت، فونت جایگزین سیستم استفاده خواهد شد.

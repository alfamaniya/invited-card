# کارت دعوت 💌

یک کارت دعوت دوستانه و تعاملی با رابط فارسی و راست‌چین، طراحی واکنش‌گرا و تقویم شمسی.

## اجرای پروژه
کافی است فایل `index.html` را در مرورگر باز کنید. برای انتشار در GitHub Pages، هر سه فایل زیر باید در ریشه‌ی شاخه‌ی `main` قرار داشته باشند.

## ساختار فایل‌ها
- `index.html` — ساختار صفحه و منطق تعامل‌ها
- `style.css` — تمام استایل‌ها و طراحی واکنش‌گرا
- `README.md` — توضیحات پروژه

## امکانات
- نمایش کارت دعوت و پنجره‌ی تعاملی
- دکمه‌های پذیرش و پاسخ منفی
- انتخاب تاریخ شمسی از روز جاری تا پایان سال ۱۴۰۵
- پشتیبانی از نمایشگرهای کوچک، صفحه‌کلید و کاهش حرکت انیمیشن‌ها
- بدون نیاز به کتابخانه یا وابستگی خارجی

## نکته
تاریخ انتخاب‌شده فقط در همان صفحه نمایش داده می‌شود؛ فعلاً در سرور ذخیره یا برای شخص دیگری ارسال نمی‌شود.
